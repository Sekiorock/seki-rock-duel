# セキオロックデュエル 開発計画（改訂版）

改訂：2026年10月21日（v0.5 の作成時。v0.7 で作成済みの欄を更新）　依頼者の指示により、仕様書 1.0 の 12章・14章を次のように改める。

## 改訂の理由

依頼者から「ゲーム全体を通して、教科書の単元（第3章 気体 p.38〜53）を網羅的に理解できるように」との指示があった。
仕様書 1.0 では「状態方程式・分圧の法則は続編」としていたが、これを本編に取り込む。
開発の順番は「単元を先にすべて作り、そのあと対戦」とする（依頼者が選択）。
実在気体は「Z（理想気体からのずれ）の考え方まで」扱う（依頼者が選択）。ファンデルワールスの状態方程式は会話で触れるだけにする。

## 各章の作り方（v0.5 で決めた形）

1. 章の前の会話（セリフは1つ20文字以内）と、教科書の要点の解説（ボンベが動く図つき、教科書のページを表示）
2. キャラクターとの1対1のデュエル（先に5回または7回ジャスト）。相手の技あり
3. 章の後の会話
4. 確認問題「説明してみよう」：教科書の問・例題・類題・「学んだことを説明してみよう」をもとにした選択問題。まちがえた選択肢は考え違いをもとに作る
5. 仲間の獲得、ごほうびのカードパック

## 仕様書から変えた点（v0.5 まで）

- 「状態方程式・分圧の法則は続編」→ 本編の v0.6・v0.7 で作る
- ドルトンは「続編の予告役」→ 6章の相手
- ファンデルワールスは「5章の相手」→ 実在気体の 7章の相手（v0.8）。5章は状態方程式
- ストーリーの CPU は、学びながら勝てるよう「見習い」から始め、負けるたびに少し遅くなる
- 今日の5問は、道場で1回遊ぶ か ストーリー2章クリアで解放
- 5章の相手は、新しいキャラクター「アボガドロ」（物質量の精、アボカド型）にした（v0.6）
- 道場・タイムアタックは段階6までのまま。物質量カードは v0.8 の総まとめで加える
- 混合気体の段階（8・9）は、ボンベに N₂ と O₂ の2種類を入れる。開始は空気（N₂:O₂ = 4:1）。混ぜると気体は増える一方なので、物質量の和が 12 を超えたら「空気に入れ替え」て開始状態に戻す（v0.7）
- 混合気体の気体は、教科書の例（空気）に合わせて N₂ と O₂ にした。H₂ などは確認問題で扱う（v0.7）
- 7章のデュエルは、ボンベは理想気体のまま、段階6・7の総復習にした。実在気体のずれは、相手の技「Z≠1カード」（霜と同じく置けないカード）と、解説・確認問題・Z判定で扱う。Z の数値データは使わず、模式図と傾向（高温・低圧で理想気体に近い、分子間力の大きい気体ほどずれる）だけにした（v0.8）
- 総まとめ試験は、7章をクリアすると受けられる。初めて受けると隠し章が開き、パックを1つもらえる。90点以上で称号「気体マスター」（v0.8）
- ℉カードの温度は整数の℉に丸めて書く（例：300 K = 81℉）。℉の数を℃だと思って 273 を足す考え違いを「℉を℃と取り違え」とした（v0.8）
- 道場・タイムアタックの上限を段階9にした（物質量カード・混合気体まで）。昇段試験も、上の段位は段階7〜9を出す（v0.8）
