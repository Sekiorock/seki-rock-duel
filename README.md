# セキオロックデュエル（SEKIO ROCK DUEL）

高校化学「気体の性質」（ボイル・シャルルの法則）のカードゲーム。
手札の操作カードを組み合わせて、ボンベの圧力を目標にぴったり合わせる。

- 遊ぶ：https://sekiorock.github.io/seki-rock-duel/
- 現在の版：v0.5.0（キャラクター7人、ストーリー1〜4章（教科書p.38〜43）、仲間とボンベの顔／段位・パック・図鑑・タイムアタック・今日の5問／道場／練習室／日本語・英語）

調整用の数値は `src/config.js`、画面の文言（日本語・英語）は `src/text.js` にまとめてある。

読み込むファイルには `?v=版番号` を付けている。版を上げるときは、すべてのファイルで同じ番号にそろえる。

開発の計画（単元全体を網羅するための改訂版）は `docs/ROADMAP.md` にある。
